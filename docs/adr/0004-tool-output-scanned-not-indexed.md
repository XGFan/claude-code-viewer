# 工具输出不建全文索引，搜索时并行扫描源文件

全文索引只收录用户输入、Claude 回复和工具输入；勾选"包含工具输出"时，由 Rust 并行扫描源 JSONL 与 `tool-results/*.txt`，以 JSON 转义后的关键词预筛、逐行验证，结果流式返回并可取消。工具输出约占对话数据的四成（实测 3 GB 中 500 MB 以上），FTS5 trigram 索引约为原文的 3 倍，收录它会让索引从约 760 MB 增长到 2 GB 以上；而"搜工具输出"（找报错信息）是低频场景，秒级的扫描可以接受。

## Consequences

- 工具输出搜索是秒级而非毫秒级（实测 0.2–1 秒）。
- 若以后要让工具输出也走索引，需要重新评估缓存体积与首次建索引时间（当前约 2–3 分钟）。
